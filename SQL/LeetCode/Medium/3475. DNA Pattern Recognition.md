# DNA 서열 패턴 찾기

## 테이블: `Samples`

| 컬럼명 | 타입 |
|---|---|
| sample_id | int |
| dna_sequence | varchar |
| species | varchar |

- `sample_id`는 이 테이블의 고유 키입니다.
- 각 행에는 문자(A, T, G, C)로 이루어진 DNA 서열과, 그 샘플을 채취한 생물 종(species)이 들어 있습니다.

## 문제

생물학자들이 DNA 서열의 기본적인 패턴을 연구하고 있습니다. 다음 패턴들을 가진 `sample_id`를 찾아내는 쿼리를 작성하세요.

- **ATG**로 시작하는 서열 (흔히 쓰이는 시작 코돈)
- **TAA, TAG, TGA** 중 하나로 끝나는 서열 (종결 코돈)
- **ATAT** 모티프를 포함하는 서열 (단순 반복 패턴)
- **G가 3개 이상 연속**으로 나오는 서열 (예: GGG, GGGG)

결과는 `sample_id` 기준 **오름차순**으로 정렬해서 반환하세요. 결과 형식은 아래 예시와 같습니다.

## 예시

### 입력: `Samples` 테이블

| sample_id | dna_sequence | species |
|---|---|---|
| 1 | ATGCTAGCTAGCTAA | Human |
| 2 | GGGTCAATCATC | Human |
| 3 | ATATATCGTAGCTA | Human |
| 4 | ATGGGGTCATCATAA | Mouse |
| 5 | TCAGTCAGTCAG | Mouse |
| 6 | ATATCGCGCTAG | Zebrafish |
| 7 | CGTATGCGTCGTA | Zebrafish |

### 출력

| sample_id | dna_sequence | species | has_start | has_stop | has_atat | has_ggg |
|---|---|---|---|---|---|---|
| 1 | ATGCTAGCTAGCTAA | Human | 1 | 1 | 0 | 0 |
| 2 | GGGTCAATCATC | Human | 0 | 0 | 0 | 1 |
| 3 | ATATATCGTAGCTA | Human | 0 | 0 | 1 | 0 |
| 4 | ATGGGGTCATCATAA | Mouse | 1 | 1 | 0 | 1 |
| 5 | TCAGTCAGTCAG | Mouse | 0 | 0 | 0 | 0 |
| 6 | ATATCGCGCTAG | Zebrafish | 0 | 1 | 1 | 0 |
| 7 | CGTATGCGTCGTA | Zebrafish | 0 | 0 | 0 | 0 |

### 설명

- **샘플 1** (ATGCTAGCTAGCTAA)
  - ATG로 시작함 (has_start = 1)
  - TAA로 끝남 (has_stop = 1)
  - ATAT를 포함하지 않음 (has_atat = 0)
  - G가 3개 이상 연속되지 않음 (has_ggg = 0)
- **샘플 2** (GGGTCAATCATC)
  - ATG로 시작하지 않음 (has_start = 0)
  - TAA, TAG, TGA로 끝나지 않음 (has_stop = 0)
  - ATAT를 포함하지 않음 (has_atat = 0)
  - GGG를 포함함 (has_ggg = 1)
- **샘플 3** (ATATATCGTAGCTA)
  - ATG로 시작하지 않음 (has_start = 0)
  - TAA, TAG, TGA로 끝나지 않음 (has_stop = 0)
  - ATAT를 포함함 (has_atat = 1)
  - G가 3개 이상 연속되지 않음 (has_ggg = 0)
- **샘플 4** (ATGGGGTCATCATAA)
  - ATG로 시작함 (has_start = 1)
  - TAA로 끝남 (has_stop = 1)
  - ATAT를 포함하지 않음 (has_atat = 0)
  - GGGG를 포함함 (has_ggg = 1)
- **샘플 5** (TCAGTCAGTCAG)
  - 어떤 패턴에도 해당하지 않음 (모든 값 = 0)
- **샘플 6** (ATATCGCGCTAG)
  - ATG로 시작하지 않음 (has_start = 0)
  - TAG로 끝남 (has_stop = 1)
  - ATAT로 시작함 (has_atat = 1)
  - G가 3개 이상 연속되지 않음 (has_ggg = 0)
- **샘플 7** (CGTATGCGTCGTA)
  - ATG로 시작하지 않음 (has_start = 0)
  - TAA, TAG, TGA로 끝나지 않음 (has_stop = 0)
  - ATAT를 포함하지 않음 (has_atat = 0)
  - G가 3개 이상 연속되지 않음 (has_ggg = 0)

## 참고

- 결과는 `sample_id` 오름차순으로 정렬합니다.
- 각 패턴 컬럼에서 **1은 해당 패턴이 있음**, **0은 없음**을 의미합니다.

## 테스트용 테이블/데이터 생성 SQL

```sql
DROP TABLE IF EXISTS Samples;

CREATE TABLE Samples (
    sample_id     INT PRIMARY KEY,
    dna_sequence  VARCHAR(255),
    species       VARCHAR(100)
);

INSERT INTO Samples (sample_id, dna_sequence, species) VALUES
(1, 'ATGCTAGCTAGCTAA', 'Human'),
(2, 'GGGTCAATCATC',    'Human'),
(3, 'ATATATCGTAGCTA',  'Human'),
(4, 'ATGGGGTCATCATAA', 'Mouse'),
(5, 'TCAGTCAGTCAG',    'Mouse'),
(6, 'ATATCGCGCTAG',    'Zebrafish'),
(7, 'CGTATGCGTCGTA',   'Zebrafish');
```
