# 뉴스 클러스터링 (자카드 유사도)

## 문제 설명

두 문자열 `str1`, `str2`의 자카드 유사도를 구한다.

자카드 유사도 J(A, B) = |A ∩ B| / |A ∪ B|
- A, B가 모두 공집합이면 J(A, B) = 1로 정의한다.
- 다중집합(중복 허용)으로 확장하면, 교집합은 각 원소 개수의 **min**, 합집합은 각 원소 개수의 **max**를 취한다.

## 입력 형식

- `str1`, `str2` 두 문자열. 각 길이는 2 이상 1,000 이하.
- 문자열을 **두 글자씩 끊어** 다중집합의 원소로 만든다. (인덱스 0부터 1칸씩 이동)
- 영문자로만 된 글자 쌍만 유효. 공백·숫자·특수문자가 포함된 쌍은 버린다.
    - 예: `"ab+"` → `"ab"`만 원소로 사용, `"b+"`는 버림
- 대소문자는 구분하지 않는다. `"AB"`, `"Ab"`, `"ab"`는 같은 원소.

## 출력 형식

자카드 유사도에 65536을 곱한 뒤 소수점 아래를 버린 정수를 반환한다.

## 예제 입출력

| str1 | str2 | answer |
| --- | --- | --- |
| FRANCE | french | 16384 |
| handshake | shake hands | 65536 |
| aa1+aa2 | AAAA12 | 43690 |
| E=M*C^2 | e=m*c^2 | 65536 |

## 제약 조건


- 길이 최대 1,000 → 원소 최대 999개
- 65536 × 999 = 65,470,464 < 2^31 이므로 int 범위 내에서 계산 가능
